## stylix

A Rust library for reading the color palette generated by [Stylix](https://github.com/danth/stylix).

This library provides a simple way to access the generated color palette from your Rust applications.

## Usage

Add `stylix` to your `Cargo.toml` dependencies.

Then, load the palette:

```rust
use stylix::Stylix;

// The palette is loaded from ~/.config/stylix/palette.json
match Stylix::load() {
    Ok(palette) => {
        println!("Scheme: {}", palette.scheme);
        println!("Base00 color: R:{} G:{} B:{}", palette.base00.r, palette.base00.g, palette.base00.b);
    }
    Err(e) => {
        eprintln!("Failed to load stylix palette: {}", e);
    }
}
```

The `Stylix::load()` function returns a `StylixPalette` struct, containing `Color` structs for each color value (e.g., `base00`, `base01`, etc.), along with `author`, `scheme`, and `slug` strings.

## Ratatui Color Support

Enable the 'ratatui-color' feature for some quality of live conversion methods.

```rust
use stylix::color::ratatui_color::From;
use stylix::color::Color as StylixColor;
use ratatui_core::style::Color as RatatuiColor;

let stylix_color = StylixColor {
    r: 255,
    g: 255,
    b: 255,
};

let ratatui_color: RatatuiColor = RatatuiColor::Rgb(255, 255, 255);

assert_eq!(stylix_color.into(), ratatui_color);

```
